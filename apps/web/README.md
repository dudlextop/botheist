# @botheist/web

The BotHeist web app: player game, organizer dashboard and campaign wizard, API route handlers and the SSE event stream (Next.js 16, App Router).

```bash
pnpm --filter @botheist/web dev    # http://localhost:3000
pnpm --filter @botheist/web e2e    # Playwright heist, with the worker running
```

See the [repository README](../../README.md) for the architecture, setup and tests.
